[ 03 · TRUST METER ]

信任关系

从演示数据中的 312 次人类审批学习：每类 action 的信任值像关系条一样升降。竖线为自动批准阈值（后验 95% 下界 ≥ 0.85）。只生成建议与 diff，不会修改你的配置。

生成的策略 diff.claude/settings.suggested.json
±
