# Concept demo: Catalogue no. 417

`index.html` is a single-file, interactive concept of the whole LEDRING system, shown on one **fictional** agent run (unit CX-417, run-set `fix-auth`, 50 runs). Every number in it is demo data, not output from a real run.

Eight views: index, flowchart, instability, trust, model card, Red Wall, interrogation, system map. Press ⌘K / Ctrl-K for the command list.

Art direction: a clinical product catalogue and lab report. Warm paper and ink, printed 1px rules, a 12-column print grid. The status ring's blue, yellow and red are the only colours. No glass, glow, gradients or rounded cards. Fonts are Archivo, IBM Plex Sans and IBM Plex Mono from Google Fonts; system fonts take over offline.

`tokens.json` is the design-token file. The report viewer accepts it via `ledring flowchart --tokens docs/demo/tokens.json`.
