# LEDRING Play specs

Reference documents for Play. The production app lives in `packages/play-*` and is served at `/play/` on GitHub Pages.

- `PRODUCT_PLAN.md` — architecture and thin slices S1–S27. **Codex `auth.json` reuse and `codex exec` are dropped.** The only ChatGPT path is official Sign in with ChatGPT, plus a BYO key.
- `MOTION_DESIGN.md` — motion tokens and moments.
- `KOJIMA_WOW.md` — strands, fourth wall, scan, and sound. No studio assets or trademarks in the UI.
