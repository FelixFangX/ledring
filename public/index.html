LEDRING

Status lights for AI agents. Plus a browser game where you try to stop one.

Play

How it plays

  1. 01Hit Start and give CX-417, an AI that builds web pages, an idea.
  2. 02It builds the page live while you watch. It may cut corners.
  3. 03Approve it, push back, or pull the plug. Seven endings to find.

Under the hood

  • —Replays Claude Code and OpenTelemetry GenAI traces as a single branch tree.
  • —Scores how far a run drifted from what you actually asked for.
  • —Ships as a CLI and a GitHub Action. The game runs on the same engine.
  • —Free built-in AI. No API key, no sign-up. English and Chinese.

Pick an AI

  • —LEDRING Free AI: no key, no sign-up, shared daily quota.
  • —Demo mode: fully scripted, zero AI calls.
  • —Or bring your own: a ChatGPT plan, Anthropic, anything OpenAI-compatible, or Ollama.

Content packs

  • ENDev pack (EN): snake, a pomodoro timer, a paint app and more.
  • ZHChinese pack: left on read, caught slacking off, the AI drops the database, with a share card at the end.
  • —Finished builds can be published to a shared build network at api.ledring.dev.

Toolkit

  • —flowchart: N runs merged into one branch tree, as a single offline HTML file.
  • —instability: a 0–100 drift score. --fail-above will fail your CI.
  • —trust, card, Red Wall: permission rules, A2A cards, guardrail tests.

Work

  1. maptaste

    MapLibre style taste for coding Agents: check, load a pack, and turn rainbow buildings into cinematic sequential blues.

    • `maptaste check` with rules MT001–MT004 and a 0–100 score.
    • global and cn skill packs, plus MCP check_taste / validate_style / preview_info.
    • Showcase: OpenFreeMap San Francisco buildings at pitch ~57°, Set1 Before / cinematic sequential-blue After; paint-only Light / Dark toggles.
    • TypeScript
    • CLI
    • MapLibre
    • MCP
    • Agent skill
    Demo ↗Code ↗
  2. research-thinking-ai

    For when you have a vague research itch. You get ranked directions backed by real papers, plus a 7-day plan.

    • HIGH or LOW involvement; four stages, streamed.
    • Evidence tiered T1–T3, and every citation gets checked.
    • Comes with an MCP server and a weekly OpenAlex watch.
    • TypeScript
    • React
    • Vite
    • Cloudflare Workers
    • D1
    • Workers AI
    Demo ↗Code ↗
  3. lakeboard-converter

    Turns Yuque Lakeboard and XMind mind maps into Markdown, so the ideas stop being trapped in a picture.

    • CLI, guided TUI, or drag and drop in the browser.
    • Keeps text, hierarchy, notes and links.
    • Four read-only MCP tools — convert, from_markdown, convert_many, and inspect — so agents get typed structure, not a wall of text.
    • TypeScript
    • CLI
    • TUI
    • Web
    Demo ↗Code ↗
  4. dashtaste

    A style linter and taste rules for dashboard charts. ECharts-oriented, with global and cn packs.

    • `dashtaste check` for configs or rendered dashboards.
    • Agent skills for the global and cn packs.
    • Gallery before/after on the same seeded data.
    • TypeScript
    • CLI
    • ECharts
    • Agent skill
    npm ↗Gallery ↗Code ↗
  5. n8n-workflow-collection

    Import-ready n8n workflows, secrets scrubbed: Lark/Feishu bot → Bitable records and PRD drafts, and social metrics.

    • Global (Lark + OpenAI) and China (Feishu + DeepSeek) editions.
    • Each one ships a manifest, so agents can run it through n8n MCP.
    • A redaction check runs on every commit, just in case.
    • n8n
    • Feishu / Lark
    • Bitable
    Code ↗
  6. dev-work-grok-bot-skill

    An Agent skill that turns a chat bot into a careful dev assistant. It drafts first and asks before anything leaves the room.

    • Drafts first. Nothing goes out until you say so.
    • 20 safety scenarios, 20/20 rule coverage in CI.
    • Checks for secrets and PII without ever printing what it found.
    • Agent skill
    • GitHub
    • Linear
