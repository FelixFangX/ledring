# Fixtures

All fixtures are **synthetic**, generated by `node scripts/gen-fixtures.mjs`, and MIT-licensed with the repo. They mirror the documented shapes of:

- `claude-code/*.jsonl` — Claude Code session transcripts (`type`, `uuid`, `parentUuid`, `sessionId`, `message.content[]` with `tool_use` / `tool_result`). Six runs of the same instruction that diverge.
- `otel/*.otlp.json` — OTLP/JSON export of OpenTelemetry GenAI spans (`invoke_agent`, `chat`, `execute_tool`). Four traces of one agent.

- `trust/*.jsonl` — eight Claude Code sessions with tool calls that ran and calls that were rejected (by a human, or by a permission rule), plus `decisions.jsonl` in the portable `ledring.decisions.v1` format.

No real transcripts, secrets or personal data.
