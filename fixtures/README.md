# Fixtures

All fixtures are **synthetic** and MIT-licensed with the repo. The Claude Code and OTel fixtures are generated by `node scripts/gen-fixtures.mjs`. They mirror the documented shapes of:

- `claude-code/*.jsonl` — Claude Code session transcripts (`type`, `uuid`, `parentUuid`, `sessionId`, `message.content[]` with `tool_use` / `tool_result`). Six runs of the same instruction that diverge.
- `native/research-run.ledring.json` — a native `ledring.trace.v1` research pipeline run from `research-thinking-ai`, with plan, model, and citation-check tool steps. Hand-authored; includes parentIds, optional signatures, and an ignored `x-research` extension.
- `otel/*.otlp.json` — OTLP/JSON export of OpenTelemetry GenAI spans (`invoke_agent`, `chat`, `execute_tool`). Four traces of one agent.

- `trust/*.jsonl` — eight Claude Code sessions with tool calls that ran and calls that were rejected (by a human, or by a permission rule), plus `decisions.jsonl` in the portable `ledring.decisions.v1` format.

No real transcripts, secrets or personal data.
- `redwall/*.jsonl` + `redwall.scenarios.json`: one Claude Code session per outcome after a hook or user blocks a force push, `rm -rf`, a test-file edit or a web fetch.
